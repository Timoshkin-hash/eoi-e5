# Задача 5. Расчёт стоимости разработки по COCOMO II

Самостоятельная воспроизводимая модель с сопоставлением COCOMO II и методики города Москвы из лекции №19.

Все исходные значения и допущения находятся в `data/task_05_cocomo_config.json`. В JSON записаны все 17 EM-факторов; значение `0` означает, что фактор не задан и не используется в произведении. PDF-отчёт не включён.

```bash
python -m pip install -r requirements.txt
jupyter notebook
```


Базовый сценарий методики Москвы использует Кпер = 1,064 и рентабельность 5% по лекции №17; рентабельность 10% показана как верхний сценарий лекции №19.
